# Data Model: Bot Protection

## Entities

### Global Rate Limit Counter

Extends the existing rate limit pattern in DynamoDB. No new table or GSI required.

| Attribute | Type | Description |
|-----------|------|-------------|
| PK | String | `RATELIMIT#global#otp-request` (fixed key for the global counter) |
| SK | String | `RATELIMIT` (matches existing rate limit sort key) |
| count | Number | Current request count within the active window |
| windowStart | String (ISO 8601) | Timestamp when the current window began |
| TTL | Number (Unix seconds) | DynamoDB TTL — auto-deletes the record after the window expires |

**Lifecycle**:
1. First request in a window: creates new record with `count=1`, `windowStart=now`, `TTL=now+60s`
2. Subsequent requests: atomic increment of `count`
3. Window expires: DynamoDB TTL deletes the record; next request starts a fresh window
4. Manual reset: delete the record (for testing/ops)

**Relationships**: None — this is a standalone counter. It does not relate to per-email or per-IP rate limit records.

**Validation Rules**:
- `count` must not exceed the configured limit (100 in production, 10000 in dev/test)
- Window duration is 60 seconds (1 minute)

### Turnstile Token (Transient — Not Persisted)

The Turnstile token is never stored in the database. It flows from the client to the backend and is verified in-flight against Cloudflare's API.

| Field | Type | Source | Description |
|-------|------|--------|-------------|
| turnstileToken | String (up to 2048 chars) | Request body | The token from the Turnstile widget |
| success | Boolean | Cloudflare siteverify response | Whether the token is valid |
| error-codes | String[] | Cloudflare siteverify response | Error codes if verification failed |

**Lifecycle**: Generated by client → sent with request → verified server-side → discarded. Tokens are single-use and expire after 300 seconds.

## Schema Changes

**None.** The global rate limit counter uses the existing DynamoDB table schema (PK/SK composite key with TTL). No new tables, GSIs, or attribute definitions are required.
